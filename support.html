First launch

Start the free 3-day trial from the access screen, then follow Setup and allow Automation access when macOS asks for permission to communicate with Music.app. The trial provides full access, does not renew and creates no automatic charge.

Music.app and standalone files

Library organization tools use the locally stored Music.app library. Audio inspection, authenticity analysis, playback, repair and conversion can also be used with standalone files opened from Finder or added by drag and drop. An Apple Music streaming subscription is not required.

Files and output folders

Add files and choose folders through the macOS system picker. If a disk or folder moved, choose it again.

Library cache

All cache controls are in Library Dashboard. Version 1.0.8 begins the transition to normalized SQLite storage: saved records and individual playlist occurrences are restored after relaunch, and large results load in pages. Warm / Refresh Selected Playlist updates only the chosen changed playlist while other warmed playlists remain available. Use a tool's clearly marked long live verification only for changes that the saved rows do not yet contain.

Audio Inspector and Authenticity Analyzer

Audio Inspector works directly with standalone files and does not need a warmed Music.app cache. Audio Authenticity Analyzer can scan the complete library, one selected playlist or an individual file. Normal files are omitted from its actionable list; Review, Likely and failed items remain visible and can be written to the local report.

Conversion

Conversion engines are built in. Do not install Homebrew or separate codecs. A CUE sheet may ask for access to the folder containing its referenced WAV, FLAC or other source audio; regular Add Files and Drag & Drop do not request extra access when the selected file is already permitted. For a problem, include the source format, chosen output profile and queue report.

Include with a support request

  • macOS version and Mac model.
  • Application version and build number.
  • Exact source format and output profile.
  • The visible error and relevant application log.
  • Whether the file is local, external or on a network volume.
