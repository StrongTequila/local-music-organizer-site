First launch

Review the safety guidance, continue into the application and allow Automation access when macOS asks for permission to control Music.app.

Files and output folders

Add files and choose folders through the macOS system picker. If a disk or folder moved, choose it again.

Conversion

Conversion engines are built in. Do not install Homebrew or separate codecs. For a problem, include the source format, chosen output profile and queue report.

Include with a support request

  • macOS version and Mac model.
  • Application version and build number.
  • Exact source format and output profile.
  • The visible error and relevant application log.
  • Whether the file is local, external or on a network volume.
