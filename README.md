# Local Music Organizer for Mac

[Local Music Organizer](https://local-music-organizer-site.pages.dev/) is a native macOS application for examining, organizing, and maintaining large offline music libraries. It works alongside Apple's Music.app, not as a replacement for it. Music and diagnostic data are processed locally.

**Official website:** https://local-music-organizer-site.pages.dev/

**Mac App Store:** https://apps.apple.com/us/app/local-music-organizer/id6790746382

## What the app does

- **Music library indexing and diagnostics:** Inspect Music.app tracks, playlists, file locations, metadata, artwork, missing files, and broken references using a private local index.
- **Duplicate detection:** Find duplicate library records, repeated playlist entries, and different quality versions of the same recording.
- **Real-time A/B listening:** Play and compare two recordings, switch between versions, and examine technical audio differences.
- **File search and maintenance:** Find audio on authorized local or external drives and review supported file and metadata maintenance tasks.
- **Audio inspection, Dynamic Range and conversion:** Inspect codecs, sample rates, bit depth, DR/LUFS/LRA and audio-quality indicators; run per-track or album DR analysis; repair or convert supported files, including supported CUE and SACD/DSD sources.
- **Batch Audio Gain:** Analyze and adjust one or more tracks or albums using manual, automatic increase or automatic decrease modes, with original-folder permission checks, clipping warnings, artwork preservation and an optional consolidated log.
- **Playlist tools and players:** Compare playlists, inspect track usage, build randomized playlists with Shuffle Builder, and use original players including a customizable 3D Glass Player.

LMO runs on **macOS 14 or later**, on both **Apple Silicon and Intel** Macs. It has a **three-day limited trial** (up to 10 permanently reserved eligible results per diagnostic tool, 10 distinct files for Audio Gain, a shared 10-file allowance for Single File Inspector and Album DR, 10 output-track conversion starts in Repair / Convert, and one completed Shuffle Builder run). Additional findings can be counted but remain locked. The Original, Classic and Glass players remain free permanently. A **US$29.99 one-time lifetime unlock** provides unlimited organizer access. There is no subscription or automatic charge.
